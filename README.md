# ☕ dio-trilha-java-básico

## 📌 Descrição

Este repositório foi criado para armazenar todos os desafios, exercícios e projetos desenvolvidos durante o bootcamp **Santander 2024 - Backend com Java**, oferecido pela DIO (Digital Innovation One).

O objetivo é acompanhar minha evolução na linguagem Java e consolidar conhecimentos fundamentais para desenvolvimento backend.

---

## 🚀 Sobre o Bootcamp

O bootcamp aborda conceitos essenciais para quem deseja iniciar na área de desenvolvimento backend com Java, incluindo:

* Lógica de programação
* Sintaxe básica do Java
* Programação Orientada a Objetos (POO)
* Estruturas de dados
* Versionamento com Git e GitHub
* Boas práticas de desenvolvimento
